## Shell, Terminal y Bash

* Shell: Programa que interpreta órdenes (comandos) que el usuario escribe.
	* Ejemplos: bash, sh, zsh, csh, powershell...
* Terminal: Programa que proporciona una interfaz gráfica o de texto para comunicarse con la shell.
	* Warp, Xterm, terminal del sistema por defecto...
* Bash (Bourne-again shell): La shell más popular en entornos Unix (Linux y macOS)

# WSL (sistema de Linux dentro de Windows)

Debes instalarlo como administrador si tienes Windows para seguir el curso.

[Instalación](https://learn.microsoft.com/es-es/windows/wsl/install)

```
wsl --install
```

* Reinicia
* Finaliza la configuración de Linux

Ya podrás usar Bash en la terminal.

> [!NOTE]
> 
> El directorio raí­z de Windows se encuentra en `/mnt/c`

Hay que tener en cuenta que WSL monta los discos dentro de /mnt, entonces:
```
C:\      → /mnt/c
D:\      → /mnt/d
```
La carpeta de Desktop de Windows sería:
```
cd /mnt/c/Users/josed/Desktop
```
Para ver la ruta en el explorador de archivos de Windows:
```
\\wsl.localhost\Ubuntu\home\josed
```

Si queremos utilizar el comando de una carpeta con espacios en blanco en medio debemos usar "\\":
```
 josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba   main  mkdir "Prueba 2"
 josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba   main  cd Prueba 2
cd: no such file or directory: /mnt/c/Users/josed/Downloads/2
 ✘ josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba   main  cd Prueba\ 2
 josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba/Prueba 2
```
