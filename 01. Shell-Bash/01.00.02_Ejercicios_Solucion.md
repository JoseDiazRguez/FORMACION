# GESTIÓN DE ARCHIVOS

## Posibles correcciones (ten en cuenta que pueden variar dependiendo de tu sistema operativo y directorios existentes)

1. Crea un directorio.

```bash
mkdir mi_directorio
# O con la opción -p para crear directorios anidados
mkdir -p directorio_padre/directorio_hijo
```

2. Elimina el directorio que acabas de crear.

```bash
rmdir mi_directorio
# Para eliminar directorios anidados vacíos
rmdir directorio_padre/directorio_hijo
rmdir directorio_padre
```

3. Copia un archivo en el directorio actual y fuera de éste.

```bash
# Copiar un archivo en el directorio actual con otro nombre
cp archivo.txt archivo_copia.txt

# Copiar un archivo a otro directorio
cp archivo.txt /ruta/al/otro/directorio/

# Copiar un archivo desde otro directorio al actual
cp /ruta/al/archivo.txt .
```

4. Mueve un archivo del directorio actual.

```bash
# Mover un archivo a otro directorio
mv archivo.txt /ruta/al/directorio_destino/

# Mover un archivo al directorio padre
mv archivo.txt ..

# Mover un archivo a un subdirectorio
mv archivo.txt subdirectorio/
```

5. Cambia el nombre del archivo que acabas de mover.

```bash
# Renombrar un archivo (mv también sirve para renombrar)
mv subdirectorio/archivo.txt subdirectorio/archivo_renombrado.txt

# O si estás en el directorio donde está el archivo
cd subdirectorio
mv archivo.txt nuevo_nombre.txt
```

6. Lista todos los archivos de un tipo usando un comodín.

```bash
# Listar todos los archivos .txt
ls *.txt

# Listar todos los archivos .sh
ls *.sh

# Listar todos los archivos .md
ls *.md

# Listar con detalles
ls -l *.txt

# Listar recursivamente todos los archivos de un tipo
ls -R *.txt
```

7. Elimina un directorio de manera recursiva (cuidado con lo que vas a borrar).

```bash
# Eliminar un directorio y todo su contenido de forma recursiva
rm -r nombre_directorio

# Con confirmación antes de eliminar
rm -ri nombre_directorio

# Forzar eliminación sin confirmación (¡CUIDADO!)
rm -rf nombre_directorio

# Forma más segura con verbose para ver qué se elimina
rm -rv nombre_directorio
```

8. Elimina todos los archivos de un mismo tipo (cuidado con lo que vas a borrar).

```bash
# Eliminar todos los archivos .txt del directorio actual
rm *.txt

# Con confirmación para cada archivo
rm -i *.txt

# Eliminar archivos de un tipo específico con verbose
rm -v *.log

# Eliminar archivos de varios tipos
rm *.txt *.log *.tmp

# Eliminar recursivamente todos los archivos de un tipo en subdirectorios
find . -name "*.txt" -type f -delete
```

9. Utiliza el comando tree.

```bash
# Mostrar árbol de directorios del directorio actual
tree

# Mostrar árbol con un nivel de profundidad específico
tree -L 2

# Mostrar solo directorios
tree -d

# Mostrar con tamaños de archivo
tree -h

# Mostrar solo archivos de un tipo específico
tree -P "*.txt"

# Mostrar árbol con todos los detalles
tree -a -h -L 3

# Si no tienes tree instalado, puedes instalarlo:
# En macOS: brew install tree
# En Linux: sudo apt-get install tree (Debian/Ubuntu)
#           sudo yum install tree (RedHat/CentOS)
```

10. Busca un archivo concreto en el directorio actual utilizando find.

```bash
# Buscar un archivo específico por nombre en el directorio actual
find . -name "archivo.txt"

# Buscar sin distinguir mayúsculas/minúsculas
find . -iname "archivo.txt"

# Buscar todos los archivos con una extensión específica
find . -name "*.sh"

# Buscar solo archivos (no directorios)
find . -type f -name "archivo.txt"

# Buscar solo directorios
find . -type d -name "mi_directorio"

# Buscar archivos modificados en las últimas 24 horas
find . -type f -mtime -1

# Buscar archivos y mostrar detalles
find . -name "*.md" -ls

# Buscar y ejecutar un comando en cada resultado
find . -name "*.txt" -exec ls -lh {} \;

# Buscar archivos por tamaño (mayores de 1MB)
find . -type f -size +1M
```



# COMANDOS AVANZADOS

## Posibles correcciones (ten en cuenta que pueden variar dependiendo de tu sistema operativo y directorios existentes)

1. Muestra todo el contenido de un archivo.

```bash
# Mostrar todo el contenido de un archivo
cat archivo.txt

# Mostrar con números de línea
cat -n archivo.txt

# Mostrar múltiples archivos
cat archivo1.txt archivo2.txt
```

2. Muestra el contenido paginado de un archivo.

```bash
# Mostrar contenido paginado con less (más moderno y recomendado)
less archivo.txt

# Mostrar contenido paginado con more (tradicional)
more archivo.txt

# Con less puedes:
# - Usar las flechas o j/k para navegar
# - Presionar 'q' para salir
# - Buscar con '/' seguido del término
# - Usar 'n' para siguiente resultado y 'N' para anterior
```

3. Muestra las 15 primeras líneas de un archivo.

```bash
# Mostrar las 15 primeras líneas
head -n 15 archivo.txt

# O simplemente (alternativa)
head -15 archivo.txt

# Por defecto head muestra 10 líneas
head archivo.txt
```

4. Muestra las 15 últimas líneas de un archivo.

```bash
# Mostrar las 15 últimas líneas
tail -n 15 archivo.txt

# O simplemente (alternativa)
tail -15 archivo.txt

# Por defecto tail muestra 10 líneas
tail archivo.txt

# Seguir mostrando nuevas líneas en tiempo real (útil para logs)
tail -f archivo.log
```

5. Busca una palabra en un archivo.

```bash
# Buscar una palabra en un archivo con grep
grep "palabra" archivo.txt

# Buscar sin distinguir mayúsculas/minúsculas
grep -i "palabra" archivo.txt

# Mostrar número de línea donde aparece
grep -n "palabra" archivo.txt

# Buscar en múltiples archivos
grep "palabra" *.txt

# Buscar recursivamente en directorios
grep -r "palabra" .

# Buscar la línea completa que contiene la palabra
grep -w "palabra" archivo.txt

# Contar cuántas líneas contienen la palabra
grep -c "palabra" archivo.txt
```

6. Cuenta las líneas de un archivo.

```bash
# Contar líneas de un archivo con wc (word count)
wc -l archivo.txt

# Mostrar líneas, palabras y bytes
wc archivo.txt

# Solo palabras
wc -w archivo.txt

# Solo bytes
wc -c archivo.txt

# Contar líneas de múltiples archivos
wc -l *.txt
```

7. Redirige una salida y guárdala en un archivo.

```bash
# Redirigir salida estándar a un archivo (sobrescribe)
ls -l > listado.txt

# Redirigir salida de cualquier comando
echo "Hola mundo" > saludo.txt

# Redirigir salida de error
comando_que_falla 2> errores.txt

# Redirigir tanto salida estándar como error al mismo archivo
comando > salida.txt 2>&1

# Forma moderna (Bash)
comando &> salida.txt

# Descartar salida (enviar a /dev/null)
comando > /dev/null
```

8. Añade una nueva salida al archivo anterior.

```bash
# Añadir (append) salida al final de un archivo existente con >>
echo "Nueva línea" >> saludo.txt

# Añadir resultado de un comando
date >> saludo.txt

# Añadir listado al archivo anterior
ls -l >> listado.txt

# Añadir errores al archivo de errores
comando_que_falla 2>> errores.txt

# Añadir tanto salida estándar como error
comando >> salida.txt 2>&1
```

9. Encadena 3 comandos.

```bash
# Encadenar con pipe (|) - la salida de uno es entrada del siguiente
ls -l | grep "txt" | wc -l

# Otro ejemplo: listar, filtrar y ordenar
cat archivo.txt | grep "error" | sort

# Ejemplo más complejo: buscar, contar y guardar
find . -name "*.sh" | wc -l | tee resultado.txt

# Encadenar con AND (&&) - ejecuta el siguiente solo si el anterior tuvo éxito
mkdir nuevo_dir && cd nuevo_dir && touch archivo.txt

# Encadenar con OR (||) - ejecuta el siguiente solo si el anterior falló
comando1 || comando2 || comando3

# Encadenar con punto y coma (;) - ejecuta todos sin importar el resultado
echo "Primero" ; echo "Segundo" ; echo "Tercero"
```

10. Crea una variable local y muéstrala.

```bash
# Crear una variable local (sin espacios alrededor del =)
nombre="Juan"

# Mostrar el valor de la variable con echo
echo $nombre

# Mostrar con llaves (recomendado)
echo ${nombre}

# Crear variable numérica
edad=25
echo $edad

# Crear variable con resultado de comando
fecha=$(date)
echo $fecha

# Alternativa con backticks (antigua)
fecha=`date`
echo $fecha

# Mostrar con texto
echo "Mi nombre es $nombre y tengo $edad años"

# Ver todas las variables
set

# Ver solo variables de entorno
env
```



# EDITORES BÁSICOS

## Posibles correcciones (ten en cuenta que pueden variar dependiendo de tu sistema operativo y directorios existentes)

### nano

1. Crea un archivo llamado nota.txt y escribe tres líneas de texto.

**Solución:**
```bash
# Abrir nano con el archivo nota.txt
nano nota.txt

# Una vez dentro de nano:
# - Escribe tus tres líneas de texto, por ejemplo:
#   Esta es la primera línea
#   Esta es la segunda línea
#   Esta es la tercera línea
# - Presiona Ctrl + O (WriteOut) para guardar
# - Presiona Enter para confirmar el nombre del archivo
# - Presiona Ctrl + X para salir
```

2. Abre nota.txt, añade una línea al final y guarda los cambios.

**Solución:**
```bash
# Abrir el archivo existente
nano nota.txt

# Una vez dentro:
# - Mueve el cursor al final del archivo con Alt + / (o flechas)
# - Añade una nueva línea: "Esta es la cuarta línea"
# - Presiona Ctrl + O para guardar
# - Presiona Enter para confirmar
# - Presiona Ctrl + X para salir
```

3. Abre un archivo nuevo llamado recordatorio.txt, escribe algo y sal sin guardar.

**Solución:**
```bash
# Abrir nano con el nuevo archivo
nano recordatorio.txt

# Una vez dentro:
# - Escribe cualquier texto: "Este es un recordatorio temporal"
# - Presiona Ctrl + X para salir
# - Cuando pregunte "Save modified buffer?", presiona N (No)
# - El archivo no se guardará y nano se cerrará
```

4. Busca una palabra específica en un archivo existente.

**Solución:**
```bash
# Abrir un archivo existente
nano nota.txt

# Una vez dentro:
# - Presiona Ctrl + W (Where is / buscar)
# - Escribe la palabra que quieres buscar, por ejemplo: "segunda"
# - Presiona Enter
# - El cursor se moverá a la primera ocurrencia
# - Para buscar la siguiente ocurrencia, presiona Alt + W
# - Presiona Ctrl + X para salir
```

5. Corta una línea y pégala en otra parte.

**Solución:**
```bash
# Abrir el archivo
nano nota.txt

# Una vez dentro:
# - Mueve el cursor a la línea que quieres cortar
# - Presiona Ctrl + K (Kill/Cortar) para cortar la línea completa
# - Mueve el cursor a donde quieres pegar la línea
# - Presiona Ctrl + U (Uncut/Pegar) para pegar la línea
# - Presiona Ctrl + O para guardar, Enter para confirmar
# - Presiona Ctrl + X para salir

# Nota: Puedes presionar Ctrl + K múltiples veces para cortar varias líneas
# y luego Ctrl + U una vez para pegarlas todas juntas
```

### vim

6. Crea apuntes.txt, entra en modo inserción y escribe una frase.

**Solución:**
```bash
# Abrir vim con el archivo apuntes.txt
vim apuntes.txt

# Una vez dentro de vim:
# - Por defecto estás en modo NORMAL
# - Presiona i para entrar en modo INSERT (inserción)
# - Verás "-- INSERT --" en la parte inferior
# - Escribe una frase, por ejemplo: "Estos son mis apuntes de Bash"
# - Presiona Esc para volver al modo NORMAL
# - Escribe :wq y presiona Enter para guardar y salir
#   (w = write/guardar, q = quit/salir)
```

7. Mueve el cursor sin usar las flechas.

**Solución:**
```bash
# Abrir el archivo en vim
vim apuntes.txt

# En modo NORMAL (presiona Esc si estás en otro modo):
# Movimientos básicos:
# - h = mover a la izquierda
# - j = mover abajo
# - k = mover arriba
# - l = mover a la derecha

# Movimientos por palabra:
# - w = siguiente palabra (word)
# - b = palabra anterior (back)
# - e = final de palabra (end)

# Movimientos de línea:
# - 0 = inicio de la línea
# - $ = final de la línea
# - ^ = primer carácter no blanco de la línea

# Movimientos de archivo:
# - gg = ir al inicio del archivo
# - G = ir al final del archivo
# - :10 = ir a la línea 10

```

8. Borra una línea completa y deshaz el cambio.

**Solución:**
```bash
# Abrir el archivo en vim
vim apuntes.txt

# En modo NORMAL (presiona Esc):
# - Coloca el cursor en cualquier línea
# - Presiona dd para borrar la línea completa
# - La línea se borrará

# Para deshacer el cambio:
# - Presiona u (undo)
# - La línea reaparecerá

# Otros comandos de borrado útiles:
# - x = borrar un carácter
# - dw = borrar una palabra
# - d$ = borrar desde el cursor hasta el final de la línea
# - D = igual que d$ (borrar hasta el final)

# Para rehacer (opuesto a deshacer):
# - Presiona Ctrl + r (redo)

# Sal sin guardar con :q!
```

9. Copia una línea y pégala debajo.

**Solución:**
```bash
# Abrir el archivo en vim
vim apuntes.txt

# En modo NORMAL (presiona Esc):
# - Coloca el cursor en la línea que quieres copiar
# - Presiona yy para copiar (yank) la línea completa
# - Mueve el cursor a donde quieres pegar
# - Presiona p para pegar debajo de la línea actual
#   (o P para pegar arriba de la línea actual)

# Otros comandos de copia útiles:
# - yw = copiar una palabra
# - y$ = copiar desde el cursor hasta el final de la línea
# - 3yy = copiar 3 líneas

# Copiar y cortar:
# - yy copia (yank)
# - dd corta (delete), pero también lo guarda para pegar
# - p pega (put/paste)

# Guarda con :w o sal con :q! si no quieres guardar
```

10. Guarda los cambios y sal.

**Solución:**
```bash
# Estando en vim con cambios realizados:

# En modo NORMAL (presiona Esc):
# - Escribe :wq y presiona Enter
#   (write + quit = guardar y salir)

# Alternativas:
# - :x = guardar y salir (si hay cambios)
# - :w = solo guardar, sin salir
# - :q = solo salir (si no hay cambios)
# - :q! = salir sin guardar (forzar)
# - :wq! = guardar y salir forzado
# - ZZ = guardar y salir (en modo NORMAL, sin necesidad de :)
# - ZQ = salir sin guardar (en modo NORMAL)

# Guardar con nombre diferente:
# - :w nuevo_nombre.txt = guardar como nuevo archivo
# - :saveas nuevo_nombre.txt = guardar como y abrir el nuevo archivo

# Si el archivo es de solo lectura:
# - :w! = forzar escritura (si tienes permisos)
# - :w !sudo tee % = guardar con sudo
```



# ADMINISTRACIÓN DEL SISTEMA

## Posibles correcciones (ten en cuenta que pueden variar dependiendo de tu sistema operativo y directorios existentes)

1. Crea un archivo y visualiza sus permisos.

```bash
# Crear un archivo
touch mi_archivo.txt

# Visualizar sus permisos con ls -l
ls -l mi_archivo.txt

# Salida ejemplo: -rw-r--r-- 1 usuario grupo 0 Nov 1 10:00 mi_archivo.txt
# Donde:
# - primer carácter: tipo (- = archivo, d = directorio)
# - rw- = permisos del propietario (lectura, escritura)
# - r-- = permisos del grupo (solo lectura)
# - r-- = permisos de otros (solo lectura)

# Ver permisos en formato octal/numérico
stat -f "%A %N" mi_archivo.txt  # macOS
# o
stat -c "%a %n" mi_archivo.txt  # Linux
```

2. Otorga permisos de ejecución sólo al propietario en modo simbólico.

```bash
# Añadir permisos de ejecución solo al propietario (user)
chmod u+x mi_archivo.txt

# Verificar los cambios
ls -l mi_archivo.txt
# Ahora mostrará: -rwxr--r-- (la x indica ejecución para el propietario)

# Explicación del modo simbólico:
# u = user (propietario)
# g = group (grupo)
# o = others (otros)
# a = all (todos)
# + = añadir permiso
# - = quitar permiso
# = = establecer exactamente estos permisos
# r = read (lectura)
# w = write (escritura)
# x = execute (ejecución)
```

3. Cambia sus permisos a 644.

```bash
# Cambiar permisos a 644 en modo numérico/octal
chmod 644 mi_archivo.txt

# Verificar los cambios
ls -l mi_archivo.txt
# Mostrará: -rw-r--r--

# Explicación del modo numérico:
# 644 significa:
# 6 (110 en binario) = rw- = lectura y escritura para el propietario
# 4 (100 en binario) = r-- = solo lectura para el grupo
# 4 (100 en binario) = r-- = solo lectura para otros

# Tabla de valores:
# 0 = --- (sin permisos)
# 1 = --x (ejecución)
# 2 = -w- (escritura)
# 3 = -wx (escritura y ejecución)
# 4 = r-- (lectura)
# 5 = r-x (lectura y ejecución)
# 6 = rw- (lectura y escritura)
# 7 = rwx (todos los permisos)
```

4. Elimina los permisos para el grupo.

```bash
# Eliminar todos los permisos del grupo con modo simbólico
chmod g-rwx mi_archivo.txt
# O más simple (eliminar todos los permisos del grupo):
chmod g= mi_archivo.txt

# Verificar los cambios
ls -l mi_archivo.txt
# Mostrará: -rw----r-- (el grupo ya no tiene permisos)

# Alternativa con modo numérico (de 644 a 604):
chmod 604 mi_archivo.txt

# Otras formas de quitar permisos específicos al grupo:
# chmod g-r mi_archivo.txt  # quitar solo lectura
# chmod g-w mi_archivo.txt  # quitar solo escritura
# chmod g-x mi_archivo.txt  # quitar solo ejecución
```

5. Haz que sólo pueda ejecutarse por el propietario.

```bash
# Establecer permisos para que solo el propietario pueda ejecutar
# Modo numérico: 700 (rwx para propietario, nada para grupo y otros)
chmod 700 mi_archivo.txt

# Verificar los cambios
ls -l mi_archivo.txt
# Mostrará: -rwx------ (solo el propietario tiene todos los permisos)

# Alternativa con modo simbólico:
chmod u=rwx,g=,o= mi_archivo.txt
# O desde permisos existentes:
chmod u+rwx,go-rwx mi_archivo.txt

# Si solo quieres dar ejecución (manteniendo lectura/escritura existentes):
chmod u+x,go-x mi_archivo.txt

# Permisos comunes para scripts ejecutables solo por el propietario:
# 700 = rwx------ (todos los permisos solo para el propietario)
# 500 = r-x------ (lectura y ejecución, sin escritura)
```

6. Crea una carpeta y dale permisos para que sólo el usuario pueda acceder.

```bash
# Crear una carpeta
mkdir mi_carpeta_privada

# Darle permisos solo para el propietario (700)
chmod 700 mi_carpeta_privada

# Verificar los permisos
ls -ld mi_carpeta_privada
# Mostrará: drwx------ (d indica directorio)

# Crear carpeta con permisos específicos en un solo comando
mkdir -m 700 nueva_carpeta_privada

# Explicación para directorios:
# r (lectura) = poder listar el contenido del directorio
# w (escritura) = poder crear/eliminar archivos dentro
# x (ejecución) = poder acceder/entrar al directorio

# Sin el permiso x, no puedes entrar al directorio aunque tengas r y w
# Por eso 700 (rwx------) es lo correcto para carpetas privadas
```

7. Cámbiale el propietario a otro usuario de tu sistema (si existe y tienes permisos).

```bash
# Cambiar el propietario del archivo (requiere permisos de root/sudo)
sudo chown otro_usuario mi_archivo.txt

# Verificar el cambio
ls -l mi_archivo.txt

# Cambiar propietario de un directorio
sudo chown otro_usuario mi_carpeta_privada

# Cambiar propietario recursivamente (directorio y todo su contenido)
sudo chown -R otro_usuario mi_carpeta_privada

# Cambiar propietario y grupo al mismo tiempo
sudo chown otro_usuario:otro_grupo mi_archivo.txt

# Solo cambiar el grupo (también se puede usar chgrp)
sudo chown :nuevo_grupo mi_archivo.txt
# O equivalente:
sudo chgrp nuevo_grupo mi_archivo.txt

# Ver usuarios disponibles en el sistema
cat /etc/passwd | cut -d: -f1

# Ver grupos disponibles
cat /etc/group | cut -d: -f1

# Nota: En macOS, usuarios comunes pueden ser: root, nobody
# En Linux: root, www-data, nobody, etc.
```

8. Consulta la máscara de permisos actual y calcula qué permisos por defecto tendrán los nuevos archivos.

```bash
# Consultar la máscara de permisos actual (umask)
umask

# Mostrar en formato simbólico
umask -S

# Cálculo de permisos por defecto:
# La umask elimina permisos de los permisos base
# - Archivos nuevos parten de 666 (rw-rw-rw-)
# - Directorios nuevos parten de 777 (rwxrwxrwx)

# Ejemplo: si umask es 0022
# Para archivos: 666 con máscara 022 = 644 (rw-r--r--)
# Para directorios: 777 con máscara 022 = 755 (rwxr-xr-x)

# Ejemplo: si umask es 0002
# Para archivos: 666 con máscara 002 = 664 (rw-rw-r--)
# Para directorios: 777 con máscara 002 = 775 (rwxrwxr-x)

# Ejemplo: si umask es 0077
# Para archivos: 666 con máscara 077 = 600 (rw-------)
# Para directorios: 777 con máscara 077 = 700 (rwx------)

# Probar creando un archivo
touch test_umask.txt
ls -l test_umask.txt
rm test_umask.txt
```

9. Crea un script que genere un archivo con la fecha actual. Prográmalo para ejecutarse el primer día de cada mes a medianoche.

```bash
#!/bin/bash
# Nombre: reporte_mensual.sh
# Descripción: Genera archivo de reporte mensual

# Directorio de reportes
dir_reportes="$HOME/reportes_mensuales"
mkdir -p "$dir_reportes"

# Generar nombre de archivo con fecha
fecha=$(date '+%Y-%m-%d')
mes_anio=$(date '+%Y-%m')
archivo="$dir_reportes/reporte_${mes_anio}.txt"

# Crear contenido del reporte
{
    echo "======================================"
    echo "REPORTE MENSUAL"
    echo "======================================"
    echo "Fecha de generación: $fecha"
    echo "Hora: $(date '+%H:%M:%S')"
    echo ""
    echo "Sistema: $(uname -s)"
    echo "Usuario: $USER"
    echo "Hostname: $(hostname)"
    echo ""
    echo "Directorio home: $HOME"
    echo "Espacio en disco:"
    df -h "$HOME" | tail -1
    echo ""
    echo "======================================"
} > "$archivo"

# Log de ejecución
log_file="$HOME/reportes_mensuales/ejecucion.log"
echo "[$(date '+%Y-%m-%d %H:%M:%S')] Reporte mensual generado: $archivo" >> "$log_file"
```

Configurar crontab:
```bash
# 1. Crear el script
nano ~/reporte_mensual.sh

cat ~/reportes_mensuales/reporte_*.txt

# 3. Editar crontab
crontab -e

```

Explicación de cron mensual:
```text
0 0 1 * * = Día 1 de cada mes a medianoche
0 0 15 * * = Día 15 de cada mes a medianoche

0 0 1 1 * = El 1 de enero a medianoche (anualmente)
0 0 1 */3 * = Primer día cada 3 meses (trimestral)
0 0 L * * = Último día del mes (en algunos cron, no todos)
```
