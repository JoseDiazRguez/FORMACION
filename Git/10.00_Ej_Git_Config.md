# Comando git config

| Comando | Descripción |
|--------|-------------|
| `git config`| |
| `git config --global user.name <nombre>`| configurar el nombre del Autor |
| `git config --global user.email <mail>`| configurar el mail del Autor |
| `git config --global init.defaultBranch main`| nombrar a la rama principal "main" |
| `git config --global alias.<nombre> "<comando>"`| si queremos personalizar y simplificar un <comando> llamándolo solo por el alias <nombe> |

## Autor
Git nos obliga a tener asociado siempre un autor, un identificador a quien atribuirle todas las acciones que hagamos desde Git.
Para ello usaremos:

- **Comando**: git config
- **Argumento**: (o **flag**): --global (para que afecte a nivel global en el equipo)
- **Propiedad**: user.name o user.email
- **Valor**: "*valor que queramos*"

Ejemplo:
```
git config --global user.name "JoseDR"
git config --global user.email "josediazrguez@gmail.com"
```

## Rama principal
Podemos configurar que la rama principal siempre se llame "main", anteriormente se denominaba "master", pero actualmente se le ha cambiado esta nomenclatura:
```
git config --global init.defaultBranch main
```

## Alias
Hay comandos que puedes usar frecuentemente y sean complejos de escribir y recordar, para ello existen los alias, solo con escribir <nombre> ya estaremos escribiendo el comando <comando> completo:
```
git config --global alias.<nombre> "<comando>"
```
