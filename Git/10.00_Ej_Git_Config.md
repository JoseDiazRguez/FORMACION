Git nos obliga a tener asociado siempre un autor, un identificador a quien atribuirle todas las acciones que hagamos desde Git.
Para ello usaremos:

- **Comando**: git config
- **Argumento**: (o **flag**): --global (para que afecte a nivel global en el equipo)
- **Propiedad**: user.name o user.email
- **Valor**: "*valor que queramos*"

Ejemplo:
```
git config --global user.name "JoseDR"
git config --global user.email "josediazrguez@gmail.com"
```
