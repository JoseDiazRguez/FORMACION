# WSL (sistema de Linux dentro de Windows)

Hay que tener en cuenta que WSL monta los discos dentro de /mnt, entonces:
```
C:\      → /mnt/c
D:\      → /mnt/d
```
La carpeta de Desktop de Windows sería:
```
cd /mnt/c/Users/josed/Desktop
```
Para ver la ruta en el explorador de archivos de Windows:
```
\\wsl.localhost\Ubuntu\home\josed
```

Si queremos utilizar el comando de una carpeta con espacios en blanco en medio debemos usar "\\":
```
 josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba   main  mkdir "Prueba 2"
 josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba   main  cd Prueba 2
cd: no such file or directory: /mnt/c/Users/josed/Downloads/2
 ✘ josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba   main  cd Prueba\ 2
 josed@JoseDiaz  /mnt/c/Users/josed/Downloads/Prueba/Prueba 2
```
