# Consultar el estado e historial del repositorio en Git

En Git existen comandos que permiten **consultar información del repositorio** sin modificar nada.

Los dos más importantes son:

- `git status`
- `git log`
  
```
git status → ver estado del repositorio
git log → ver historial
↓
paginador less → navegar por la salida
↓
q → salir
```

Estos comandos permiten conocer:

- el estado actual de los archivos
- el historial de cambios del proyecto
- la estructura de commits del repositorio

# git status

El comando `git status` permite ver el **estado actual del repositorio**.

Este comando muestra:

- la rama actual
- archivos modificados
- archivos preparados para commit
- archivos nuevos que Git aún no controla

Para ejecutarlo:

```
git status
```

---

# Información que muestra git status

Cuando ejecutamos `git status`, Git analiza tres áreas principales:

```
Working Directory
Staging Area
Repository (HEAD)
```

Ejemplo de salida:

```
On branch main

Changes to be committed:
  modified:   archivo.py

Changes not staged for commit:
  modified:   config.txt

Untracked files:
  nuevo_archivo.txt
```

Esto significa:

| Estado | Significado |
|------|-------------|
| Changes to be committed | archivos preparados para el próximo commit |
| Changes not staged | archivos modificados pero aún no añadidos al staging |
| Untracked files | archivos nuevos que Git todavía no controla |

# git log

El comando `git log` permite visualizar el **historial de commits** del repositorio.

Cada commit contiene información como:

- identificador único (hash)
- autor
- fecha
- mensaje del commit

Para visualizar el historial:

```
git log
```

Ejemplo de salida:

```
commit a3c4f7e21a6e4d7c7b9f
Author: Usuario <email@example.com>
Date:   Mon Mar 10 10:30:12 2025

    Añadir funcionalidad de login
```

Git muestra los commits **del más reciente al más antiguo**.

---

# Opciones más utilizadas de git log

El comando `git log` admite múltiples opciones para personalizar la visualización del historial.

| Comando | Descripción |
|-------|-------------|
| `git log` | muestra el historial completo de commits |
| `git log --oneline` | muestra cada commit en una sola línea |
| `git log --graph` | muestra el historial en forma de gráfico |
| `git log --decorate` | muestra las ramas asociadas a cada commit |
| `git log --stat` | muestra los archivos modificados en cada commit |

---

# Ejemplo de git log --oneline

```
git log --oneline
```

Salida:

```
9f2a3d1 Añadir login
5ab83c2 Crear API
2a81b4f Proyecto inicial
```

Esto permite visualizar rápidamente el historial de commits.

---

# Ejemplo de git log con gráfico

```
git log --graph --oneline
```

Salida aproximada:

```
* 9f2a3d1 Añadir login
* 5ab83c2 Crear API
* 2a81b4f Proyecto inicial
```

Si existen ramas, el gráfico muestra cómo se separan y se fusionan.

# Alias en Git

Git permite crear **alias**, que son comandos personalizados que simplifican comandos largos o complejos.

Un alias permite ejecutar un comando largo con una palabra más corta.

Por ejemplo:

```
git tree
```

puede ejecutar internamente un comando más complejo.

Los alias se definen dentro del archivo de configuración de Git:

```
~/.gitconfig
```

Ejemplo:

```
[alias]
	tree = log --graph --decorate --pretty=format:'%C(auto)%h%d %s %C(black)%C(bold)%cr' --abbrev-commit --stat
```

---

---

# Alias avanzado para visualizar el historial de commits

Podemos crear un alias muy utilizado por los desarrolladores para visualizar el historial completo del repositorio de forma gráfica.

Este alias permite ver:

- la estructura de ramas
- los commits del repositorio
- las referencias de ramas
- el tiempo relativo de cada commit
- los archivos modificados

---

## Alias `lg`

El alias `lg` muestra el historial del repositorio como un **árbol completo de commits**, incluyendo todas las ramas.

Configuración en el archivo `.gitconfig`:

```
[alias]
	lg = log --graph --decorate --pretty=format:'%C(auto)%h%d %s %C(black)%C(bold)%cr' --all --abbrev-commit --stat
```

---

## Crear el alias desde la terminal

En lugar de editar manualmente el archivo `.gitconfig`, podemos crear el alias directamente con el siguiente comando:

```
git config --global alias.lg "log --graph --decorate --pretty=format:'%C(auto)%h%d %s %C(black)%C(bold)%cr' --all --abbrev-commit --stat"
```

Este comando añade automáticamente la configuración al archivo:

```
~/.gitconfig
```

---

## Usar el alias

Una vez configurado, podemos ejecutar:

```
git lg
```

Ejemplo de salida:

```
* 9f2a3d1 (HEAD -> main) Añadir login 2 hours ago
* 5ab83c2 Crear API 1 day ago
* 2a81b4f Proyecto inicial 3 days ago
```

---

## Opciones utilizadas en el alias

| Opción | Descripción |
|------|-------------|
| `--graph` | muestra el historial como un árbol de commits |
| `--decorate` | muestra las ramas asociadas a cada commit |
| `--pretty=format` | personaliza el formato de salida |
| `--all` | muestra todas las ramas del repositorio |
| `--abbrev-commit` | muestra hashes de commit abreviados |
| `--stat` | muestra archivos modificados en cada commit |

---

# Resumen de comandos

| Comando | Uso |
|------|------|
| `git status` | ver el estado actual del repositorio |
| `git log` | ver el historial completo de commits |
| `git log --oneline` | ver el historial resumido |
| `git log --graph` | visualizar la estructura de commits |
| `git lg` | visualizar el árbol completo de commits mediante alias |

# Sobre el (END) en la terminal

Cuando ejecutamos comandos como:

```
git log
```

Git puede mostrar mucha información en pantalla.  
En estos casos, la salida no se muestra directamente en la terminal, sino que se abre en un **paginador**.

El paginador que Git utiliza por defecto se llama **less**.

Este programa permite navegar por el contenido página a página dentro de la terminal.

Por eso al final de la pantalla aparece:

```
(END)
```

Esto **no es un error**.  
Simplemente indica que hemos llegado al final del contenido mostrado.

---

## Navegar dentro del paginador

Dentro del paginador `less` podemos utilizar varias teclas:

| Tecla | Acción |
|------|--------|
| `↑` o `↓` | mover una línea arriba o abajo |
| `Space` | avanzar una página |
| `b` | retroceder una página |
| `/` | buscar texto dentro del historial |

---

## Salir del paginador

Para cerrar la vista del historial y volver a la terminal debemos pulsar:

```
q
```

Esto cerrará el paginador y volveremos al prompt de la terminal.

---

## Cuándo aparece el paginador

El paginador suele activarse cuando ejecutamos comandos como:

```
git log
```

```
git diff
```

```
git show
```

Si la salida es muy larga, Git utiliza `less` para facilitar la navegación por el contenido.
