# Mapa visual de comandos Git según el área que afectan

---

Git trabaja principalmente sobre tres áreas del proyecto:

```
Working Directory  →  Staging Area  →  Repository (HEAD)
```

Cada comando de Git actúa sobre una o varias de estas áreas.

---

# Mapa de comandos

```
                    ┌─────────────────────┐
                    │   Repository (HEAD) │
                    │  historial commits  │
                    └──────────▲──────────┘
                               │
                               │ git commit
                               │ git revert
                               │ git reset (--soft)
                               │
                    ┌──────────┴──────────┐
                    │    Staging Area     │
                    │   archivos listos   │
                    │     para commit     │
                    └──────────▲──────────┘
                               │
                               │ git add
                               │ git restore --staged
                               │ git reset (--mixed)
                               │
                    ┌──────────┴──────────┐
                    │   Working Directory │
                    │ archivos modificados│
                    └──────────▲──────────┘
                               │
                               │ git restore
                               │ git checkout <archivo>
                               │ git reset (--hard)
```

---

# Tabla resumen de comandos según el área

| Área afectada | Comandos principales | Qué hacen |
|---------------|---------------------|----------|
| **Working Directory** | `git restore` | descarta cambios en archivos |
| | `git checkout <archivo>` | restaura archivo desde el último commit |
| | `git reset --hard` | restaura completamente el proyecto |
| **Staging Area** | `git add` | añade archivos al staging |
| | `git restore --staged` | quita archivos del staging |
| | `git reset` | mueve cambios fuera del staging |
| **Repository (HEAD)** | `git commit` | crea una nueva versión del proyecto |
| | `git revert` | crea un commit que deshace otro |
| | `git reset --soft` | mueve el puntero HEAD |

---

# Resumen conceptual

```
Working Directory
        │
        │ git add
        ▼
Staging Area
        │
        │ git commit
        ▼
Repository (HEAD)
```

Comandos para **deshacer cambios** según la zona:

```
Working Directory → git restore
Staging Area      → git reset / git restore --staged
Repository        → git revert / git reset
```
