# Conceptos

## **commit**:  
Fotograffías o instantáneas del estado de nuestro proyecto en diferentes momentos a lo largo del tiempo. Git funciona mediante la creación de fotografías. Cada commit representa un conjunto de cambios realizados en el proyecto.

## **Repositorio de Git**:  
Lugar donde se almacena el historial de cambios realizados en un proyecto y las diferentes versiones del mismo, incluyendo el código fuente, la documentación y cualquier otro archivo que se encuentre en ese directorio.  
Cada versión de un archivo se almacena asociado a un commit, que contiene una instantánea de los cambios realizados en ese momento.


## Crear un repositorio git en local

Primero nos posicionamos en el Escritorio
```
cd ~/Desktop
```
Si queremos ver, en el lugar que me encuentro:
```
pwd
```
Si quiero ver el listado de todos los directorios que hay en la carpeta actual:
```
ls
```
Ahora crearemos una carpeta:
```
mkdir "<nombre_carpeta>"
```
Entraremos dentro de la carpeta creada:
```
cd nombre_carpeta
```
Y creamos un archivo (por ejemplo python):
```
touch hellogit.py
```
<img width="1226" height="314" alt="image" src="https://github.com/user-attachments/assets/6f2722ce-3cfe-482a-896c-e68c8267d5c4" />


Ahora, para abrir dicho archivo en un IDE (Visual Studio Code (VSC) por ejemplo):
```
code .
```
Y se nos abrirá con el proyecto en de la carpeta donde estábamos. 
En VSC escribimos por ejemplo: print("Hello Git!").
Ahora, **crearemos un repositorio Git, para ello escribiremos lo siguiente en Git Bash:
```
git init
```
<img width="1284" height="312" alt="image" src="https://github.com/user-attachments/assets/cd1bb30c-b558-4da7-9f38-bcda25688a4c" />

A partir de este momento, nuestro directorio (y todo lo que se encuentre en su interior) trabaja con un control de versiones, lo que significa que podemos empezar a emplear todas las características que Git nos proporciona.

Una vez que vayamos modificando nuestro proyecto, debemos guardarlo y actualizar el repositorio de Git, para ello haremos:

Añadir al área de Stage un archivo concreto:
```
git add <nombre>
```
O añadir al área de Stage todos los archivos pendientes de versionar:
```
git add .
```

A continuación, si queremos grabar una fotografía de todo lo que tenemos en el área de Stage, agragándole un mensaje (texto explicativo de las modificaciones de esta versión), haremos:
```
git commit -m "<mensaje>"
```
