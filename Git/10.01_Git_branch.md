# Ramas (llamadas *branch*)

Podemos usar *ramas* para el desarrollo de distintas funcionalidades, corrección de errores, probar nuestros conceptos, etc.

| Comando | Descripción |
|--------|-------------|
| `git config --global init.defaultBranch main`| nombrar a la rama principal "main" |
| `git branch -m <nombre_rama>`| para cambiar la rama actual |
