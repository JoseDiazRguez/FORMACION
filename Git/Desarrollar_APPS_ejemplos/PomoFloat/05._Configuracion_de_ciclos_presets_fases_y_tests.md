## 5. Error detectado: atributo `cycle` inexistente

Durante el desarrollo apareció:

```text
AttributeError:
'CycleEditor' object has no attribute 'cycle'
```

La causa era el orden del constructor.

Se estaba ejecutando:

```python
self._load_cycle()
```

antes de:

```python
self.cycle = cycle
```

La solución fue inicializar primero el estado:

```python
self.cycle = cycle

self._create_ui()
self._load_cycle()
```

Lección:

> Los métodos llamados desde `__init__()` solo pueden utilizar atributos que ya hayan sido creados previamente.

## 33. Visualización `hh:mm:ss`

El temporizador pasó de:

```text
88:24
```

a:

```text
01:28:24
```

El cálculo:

```python
hours, remainder = divmod(
    total_seconds,
    3600,
)

minutes, seconds = divmod(
    remainder,
    60,
)
```

y después:

```python
f"{hours:02d}:{minutes:02d}:{seconds:02d}"
```

Ejemplos:

```text
10 segundos     → 00:00:10
25 minutos      → 00:25:00
1 h 28 min 24 s → 01:28:24
10 horas        → 10:00:00
```

## 44. Lecciones principales

### Separar UI, dominio y almacenamiento

La arquitectura:

```text
UI
↓
Cycle / Phase
↓
CycleStorage
↓
JSON
```

facilita mantener el proyecto y añadir tests.

### Un popup también puede ser una ventana

Controles como:

```text
QComboBox
QMessageBox
QDialog
```

pueden crear ventanas secundarias aunque visualmente parezcan parte de la aplicación.

Esto fue especialmente relevante bajo WSLg.

### Guardar segundos internamente fue una buena decisión

El modelo trabaja con:

```python
duration_seconds
```

por lo que pasar de minutos a minutos+segundos no requirió cambiar:

```text
TimerEngine
CycleStorage
JSON
```

Solo cambió la interfaz.

### Persistencia debe probarse con round trips

No basta con probar:

```text
guardar
```

También hay que probar:

```text
guardar
↓
cargar
↓
comparar
```

### Los tests no deben tocar datos reales

Gracias a:

```python
tmp_path
```

los tests no afectan al archivo del usuario.
