# 11. ¿Qué hace `-u`?

La opción:

```text id="5kjrln"
-u
```

equivale a:

```text id="hmvx98"
--set-upstream
```

Esto vincula la rama local:

```text id="3q9r4j"

```

con:

```text id="l3k0gu"

```

Por tanto:

```text id="hz4oyh"
main local
    ↕
origin/main
```

A partir de ese momento no es necesario escribir siempre:

```bash id="8hkqn4"
git push origin main
```

Basta con:

```bash id="tt36ht"
git push
```

# 20. SSH frente a HTTPS

En este proyecto se está utilizando:

```text id="29576k"
git@github.com:JoseDiazRguez/PomoFloat.git
```

Eso indica que la conexión se realiza mediante:

```text id="wgsluz"
SSH
```

en lugar de HTTPS.

Una URL HTTPS sería parecida a:

```text id="5b8czj"

```

Una URL SSH tiene normalmente esta estructura:

```text id="xvuljl"

```

SSH es especialmente cómodo para trabajar de forma frecuente con GitHub porque permite autenticar mediante claves SSH.

# 32. Crear `phase.py`


Código:

```python id="ue86nv"
from dataclasses import dataclass


@dataclass
class Phase:
    name: str
    duration_seconds: int
    auto_start_next: bool = True

    def __post_init__(self) -> None:
        if not self.name.strip():
            raise ValueError("Phase name cannot be empty.")

        if self.duration_seconds <= 0:
            raise ValueError("Phase duration must be greater than 0 seconds.")
```

---

# 33. ¿Qué es `@dataclass`?

Se importa desde:

```python id="9p5kla"
from dataclasses import dataclass
```

Y se utiliza:

```python id="8asbn6"
@dataclass
class Phase:
```

`dataclass` simplifica la creación de clases cuyo objetivo principal es almacenar datos.

Sin `dataclass` habría que escribir algo similar a:

```python id="41kr6n"
class Phase:
    def __init__(
        self,
        name: str,
        duration_seconds: int,
        auto_start_next: bool = True,
    ):
        self.name = name
        self.duration_seconds = duration_seconds
        self.auto_start_next = auto_start_next
```

Con:

```python id="ii2qny"
@dataclass
```

Python genera automáticamente buena parte de ese código.

# 36. Validar el nombre

Código:

```python id="45tgtq"
if not self.name.strip():
    raise ValueError("Phase name cannot be empty.")
```

Esto evita fases cuyo nombre sea vacío.

No sería válido:

```python id="8kw1fx"
Phase(
    name="",
    duration_seconds=1500,
)
```

Tampoco:

```python id="ws1pj9"
Phase(
    name="   ",
    duration_seconds=1500,
)
```

porque:

```python id="0sbrjo"
strip()
```

elimina los espacios al inicio y al final.

---

```python id="10lz9m"
import pytest

from pomofloat.core.phase import Phase


def test_phase_creation() -> None:
    phase = Phase(
        name="Concentración",
        duration_seconds=1500,
    )

    assert phase.name == "Concentración"
    assert phase.duration_seconds == 1500
    assert phase.auto_start_next is True


def test_phase_can_disable_auto_start() -> None:
    phase = Phase(
        name="Descanso",
        duration_seconds=300,
        auto_start_next=False,
    )

    assert phase.auto_start_next is False


def test_phase_name_cannot_be_empty() -> None:
    with pytest.raises(ValueError):
        Phase(
            name="",
            duration_seconds=1500,
        )


def test_phase_duration_must_be_positive() -> None:
    with pytest.raises(ValueError):
        Phase(
            name="Concentración",
            duration_seconds=0,
        )
```
