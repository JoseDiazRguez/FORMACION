La **Integración Continua**, o **CI — Continuous Integration**, consiste en ejecutar automáticamente una serie de comprobaciones cada vez que se modifica el código.

class DraggableFrame(QFrame):
    def mousePressEvent(self, event: QMouseEvent) -> None:
        if event.button() == Qt.MouseButton.LeftButton:
            window = self.window()

                event.accept()

# 47. Por qué usamos `-d` y no `-D`

```bash
git branch -d ...
```

solo elimina una rama local si Git considera que sus cambios ya están integrados.

En cambio:

```bash
git branch -D ...
```

fuerza la eliminación.

Para un flujo normal es preferible:

```text
-d
```

porque añade una protección adicional.

# 51. Lecciones principales

## GitHub Actions

Un Pull Request puede convertirse en una puerta de calidad automática:

```text
PR
↓
tests
↓
merge solo si todo está correcto
```

---

## YAML es sensible a claves exactas

```yaml
branch:
```

no equivale a:

```yaml
branches:
```

Un pequeño error puede cambiar completamente cuándo se ejecuta un workflow.

---

## Una Pull Request sigue a la rama

No es necesario crear un nuevo PR por cada corrección.

```text
PR abierto
   ↓
nuevo commit en la misma feature
   ↓
PR actualizado
```

---

## Separar GUI y lógica facilita el testing

```text
TimerEngine ≠ PySide6
```

El motor continúa siendo independiente y testable.

---

## Las ventanas frameless requieren gestionar comportamiento adicional

Al eliminar el marco nativo también se pierden comportamientos estándar como:

- mover desde la barra de título;
- cerrar;
- maximizar;
- redimensionar.

Hay que reconstruir explícitamente aquello que necesite la aplicación.

---

## Una vista compacta debe diseñarse como una vista propia

No basta con reducir dimensiones.

La solución más limpia fue:

```text
normal_view
compact_view
```

en lugar de intentar reutilizar exactamente el mismo layout.

---

## WSLg no equivale a ejecución nativa

WSLg es excelente para desarrollo, pero determinadas funciones relacionadas con el gestor de ventanas pueden comportarse de forma diferente.

Por eso:

```text
funciona/no funciona en WSLg
```

no implica necesariamente:

```text
funciona/no funciona en Windows nativo
```
