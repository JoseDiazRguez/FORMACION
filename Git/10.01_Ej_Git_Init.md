Conceptos:

**commit**: Fotograffías o instantáneas del estado de nuestro proyecto en diferentes momentos a lo largo del tiempo. Git funciona mediante la creación de fotografías. Cada commit representa un conjunto de cambios realizados en el proyecto.
**Repositorio de Git**: Lugar donde se almacena el historial de cambios realizados en un proyecto y las diferentes versiones del mismo, incluyendo el código fuente, la documentación y cualquier otro archivo que se encuentre en ese directorio.


## Crear un repositorio git en local

Primero nos posicionamos en el Escritorio
```
cd ~/Desktop
```
Si queremos ver, en el lugar que me encuentro:
```
pwd
```
Si quiero ver el listado de todos los directorios que hay en la carpeta actual:
```
ls
```
Ahora crearemos una carpeta:
```
mkdir "nombre_carpeta"
```
Entraremos dentro de la carpeta creada:
```
cd nombre_carpeta
```
Y creamos un archivo (por ejemplo python):
```
touch hellogit.py
```

Ahora, para abrir dicho archivo en un IDE (Visual Studio Code (VSC) por ejemplo):
```
code .
```
Y se nos abrirá con el proyecto en de la carpeta donde estábamos. 
En VSC escribimos por ejemplo: print("Hello Git!").
Ahora, **crearemos un repositorio Git, para ello escribiremos lo siguiente en Git Bash:
```
git init
```
